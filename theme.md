# Canvasly Cozy UI Theme

## Personality
Canvasly should feel fresh, focused, and quietly warm. The product combines structured pages, AI assistance, planning, and open-ended whiteboarding, so the interface should stay calm while still using enough color to make work feel alive.

## Color Palette
- Background: warm fresh off-white, `hsl(42 72% 98%)`
- Surface: clean white, `hsl(0 0% 100%)`
- Text: soft charcoal, `hsl(215 26% 17%)`
- Muted text: clear slate gray, `hsl(216 16% 42%)`
- Primary: vivid mint green, `hsl(169 66% 34%)`
- Secondary: airy mint, `hsl(174 58% 93%)`
- Accent: fresh sky, `hsl(199 88% 92%)`
- Border: cool soft neutral, `hsl(198 28% 86%)`
- Supporting accents: sky, coral, amber, lavender, teal, emerald, and indigo.

## Typography
- Use the system font stack for a native, fast, app-like feel.
- Keep dashboard and sidebar text compact and highly scannable.
- Use sentence case for most labels and short headings.
- Avoid oversized marketing-style typography inside the app shell.
- Keep letter spacing at the default value.

## Spacing And Shape
- Use compact spacing in persistent navigation.
- Sidebar menu rows should be about `36px` tall.
- Use `8px` border radius for buttons, panels, sidebar items, and workspace cards.
- Keep shadows subtle and soft; rely more on spacing, borders, and background contrast.
- Avoid nested card layouts. Use individual cards only for repeated items, panels, or contained tools.

## Sidebar Guidelines
- Expanded sidebar width: about `248px`.
- Collapsed sidebar width: about `76px`.
- Collapsed sidebar shows icons only.
- Group labels hide when collapsed.
- Expanded sidebar groups should have visible labels and subtle grouped backgrounds.
- Every menu item uses a Lucide icon with a distinct, balanced accent color.
- Active navigation should use a soft primary tint, not a heavy filled state.
- Footer content should adapt to the collapsed state without showing cramped text.

## Dashboard Guidelines
- The dashboard should feel like a working app screen, not a landing page.
- Use lightweight previews for tasks, notes, calendar, whiteboard, and AI workflows until those features become interactive.
- Prioritize clean information density, fast scanning, and comfortable whitespace.
- Keep controls obvious, with icons for common actions and concise text for commands.
